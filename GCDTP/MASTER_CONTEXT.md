# Master Context

## Project Vision

GCDTP provides a minimal yet comprehensive project structure that can be adapted for any software initiative. It establishes conventions for documentation, architecture, and organization without imposing specific technology choices.

## Goals

- Provide a clean starting point for new projects
- Establish consistent folder structure and naming conventions
- Document architectural decisions systematically
- Enable rapid project bootstrapping

## Constraints

- No business logic included (placeholder only)
- No specific APIs defined
- No database configurations required
- No external dependencies beyond placeholders

## Core Principles

1. **Separation of Concerns** - Each folder has a single, clear purpose
2. **Documentation First** - All decisions are documented and traceable
3. **Extensibility** - Structure supports growth without refactoring
4. **Minimal Viable** - Only essential elements included
