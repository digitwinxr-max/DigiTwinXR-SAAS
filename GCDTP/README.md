# GCDTP

> Generic Component-Driven Template Project

## Overview

A clean, extensible project template with structured architecture.

## Repository Structure

```
GCDTP/
├── adr/           # Architecture Decision Records
├── backend/       # Backend service placeholder
├── database/      # Database migrations placeholder
├── frontend/      # Frontend application placeholder
├── tests/         # Test suites placeholder
├── docker-compose.yml
├── MASTER_CONTEXT.md
└── ROADMAP.md
```

## Getting Started

### Prerequisites

- Docker & Docker Compose
- Python 3.11+ (for backend development)
- Node.js 18+ (for frontend development)

### Quick Start

```bash
docker-compose up --build
```

## Placeholder Services

This template includes placeholder structure for:

- **Backend**: FastAPI/Python service framework
- **Frontend**: React/TypeScript application framework  
- **Database**: PostgreSQL/PostGIS schema
- **Tests**: Integration and E2E test infrastructure
